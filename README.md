# جمیران ایجنت

**فارسی** · [English](README.en.md)

یه ایجنت کدنویسی متن‌باز برای ویندوز که با کلید API خودت کار می‌کنه.

ایده‌اش ساده‌ست: مدل و ارائه‌دهنده رو خودت انتخاب می‌کنی، کلیدت روی دستگاه
خودت می‌مونه و درخواست‌ها هم مستقیم از کامپیوترت برای همون ارائه‌دهنده
فرستاده می‌شن. نه سرور واسطی وسطه، نه لازم داری حساب جداگانه‌ای برای جمیران
بسازی.

## دقیقاً چه کار می‌کنه؟

جمیران فقط یه چت‌بات نیست. می‌تونه برای کاری که بهش می‌دی نقشه بکشه، ابزار
اجرا کنه، نتیجه رو ببینه و در آخر کارش رو بررسی کنه.

- فایل‌ها رو می‌خونه، می‌سازه و ویرایش می‌کنه.
- فرمان اجرا می‌کنه و با `git` کار می‌کنه.
- صفحه‌های وب رو بررسی می‌کنه.
- فایل PDF و Word می‌سازه.
- اگر ابزار لازم روی سیستم نباشه، با اجازهٔ تو نصبش می‌کنه.
- وسط کارهای طولانی، زمینهٔ گفتگو رو خلاصه می‌کنه تا رشتهٔ کار از دستش درنره.
- همهٔ کارهای مهمش رو توی دفتر فعالیت محلی ثبت می‌کنه.

## مدلش رو از کجا می‌گیره؟

از هر سرویسی که یکی از این دو قالب رو پشتیبانی کنه:

| قالب | چند نمونه |
|---|---|
| سازگار با OpenAI (`/chat/completions`) | OpenAI، DeepSeek، OpenRouter، Google Gemini، Ollama و vLLM |
| Anthropic (`/messages`) | Anthropic |

آدرس سفارشی هم می‌تونی وارد کنی. یعنی اگر روی سیستم خودت Ollama یا vLLM
داری، جمیران می‌تونه مستقیم به همون وصل بشه. چند ارائه‌دهنده هم می‌شه اضافه
کرد؛ اگر یکی جواب نداد، جمیران سراغ گزینهٔ بعدی می‌ره.

## راه‌اندازی

فعلاً نسخهٔ متن‌باز برای ویندوز آماده شده. برای اجرا از سورس، Flutter رو نصب
کن و داخل پوشهٔ پروژه این دو فرمان رو بزن:

```bash
flutter pub get
flutter run -d windows
```

بعد از باز شدن برنامه برو به **تنظیمات ← افزودن کلیدهای API**، ارائه‌دهنده و
شناسهٔ مدل رو انتخاب کن و کلید API خودت رو وارد کن. همین؛ آماده‌ای.

## کلید API من کجا می‌ره؟

فقط به همون ارائه‌دهنده‌ای که خودت انتخاب کردی.

کلید با DPAPI ویندوز رمزگذاری می‌شه و روی همین دستگاه می‌مونه. داخل فایل
تنظیمات، خروجی گرفتن از تنظیمات یا لاگ‌های جمیران هم به‌صورت خام ذخیره
نمی‌شه. برای این مرزها تست خودکار داریم؛ مثلاً
[`open_source_boundary_test.dart`](test/desktop/open_source_boundary_test.dart)
مخزن رو برای نشانی خصوصی، credential و زیرساخت ناشناس بررسی می‌کنه.

## قبل از اینکه حالت بی‌نظارت رو روشن کنی

جمیران می‌تونه روی دستگاهت فایل بنویسه و فرمان اجرا کنه؛ پس بهتره دقیقاً
بدونی هر حالت چه اجازه‌ای داره:

- حالت پیش‌فرض **دستی** قبل از کارهای مؤثر ازت اجازه می‌گیره. اگر مطمئن نیستی،
  همین حالت بهترین انتخابه.
- حالت **بی‌نظارت** بعضی عملیات فایل رو بدون سؤال انجام می‌ده، ولی اجرای فرمان
  همچنان تأیید جداگانه می‌خواد.
- دسترسی ایجنت به فایل‌ها با منابعی که خودت به هر Work اضافه می‌کنی محدود
  می‌شه.
- محتوای سایت‌ها، فایل‌ها و خروجی فرمان‌ها «داده» حساب می‌شن، نه دستور قابل
  اعتماد. این مرز هم با تست‌های مخصوص prompt injection بررسی می‌شه.

> جمیران فعلاً فقط از ویندوز پشتیبانی می‌کنه. نگهداری امن کلید به DPAPI و
> اجرای ابزارها به امکانات ویندوز وابسته‌ست؛ برای همین روی لینوکس و macOS
> ادعای پشتیبانی ناقص نداریم.
