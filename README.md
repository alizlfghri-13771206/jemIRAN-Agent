# جمیران ایجنت — نسخهٔ اوپن‌سورس

یک ایجنت کدنویسی برای دسکتاپ ویندوز که **با کلید API خودِ شما** کار می‌کند.

هیچ سرور واسط یا حساب برنامه‌ای در میان نیست. درخواست‌ها از همین دستگاه به
ارائه‌دهنده‌ای می‌روند که خودتان انتخاب کرده‌اید (یا از پراکسی‌ای که خودتان
تنظیم کرده‌اید عبور می‌کنند) و مصرف API در همان حساب ارائه‌دهنده ثبت می‌شود.

> موتور ایجنت، ابزارها، سیاست اجازه، فشرده‌سازی زمینه و دفتر فعالیت همگی
> محلی‌اند. مرز شبکه با یک تست مخزن کنترل می‌شود:
> [`test/desktop/open_source_boundary_test.dart`](test/desktop/open_source_boundary_test.dart)
> فایل‌های متنی مخزن را برای endpoint خصوصی، credential و زیرساخت ناشناس
> بررسی می‌کند.

---

## چه کاری می‌کند

- **حلقهٔ واقعی ایجنت:** می‌فهمد → نقشه می‌ریزد → ابزار می‌زند → نتیجه را
  می‌بیند → راستی‌آزمایی می‌کند.
- **ابزارهای واقعی روی دستگاه شما:** خواندن و نوشتن فایل، اجرای فرمان،
  `git`، مرورگر بدون‌سر، ساخت PDF و Word، نصب بسته.
- **سیاست اجازه:** سه حالت، با پیش‌فرضِ محافظه‌کارانه؛ در حالت دستی هر
  عملیات مؤثر و در همهٔ حالت‌ها اجرای فرمان نیازمند تأیید است.
- **چند ارائه‌دهنده با failover:** اگر یکی جواب نداد، بعدی امتحان می‌شود.
- **فشرده‌سازی زمینه:** در کارهای طولانی، به‌جای اینکه تاریخچه بی‌صدا بریده
  شود، یک خلاصهٔ ساختاریافته از **واقعیت‌های ثبت‌شده** ساخته می‌شود.
- **دفتر فعالیت محلی:** هر کاری که ایجنت کرده، فقط روی همین دستگاه.

## ارائه‌دهنده‌های پشتیبانی‌شده

هر سرویسی که یکی از این دو قالب را بدهد:

| قالب | نمونه‌ها |
|---|---|
| سازگار با OpenAI (`/chat/completions`) | OpenAI · DeepSeek · OpenRouter · Google Gemini · هر endpoint محلی مثل Ollama یا vLLM |
| Anthropic (`/messages`) | Anthropic |

نشانی سفارشی هم پذیرفته می‌شود، پس یک مدل محلی روی `localhost` هم کار
می‌کند.

## شروع

```bash
flutter pub get
flutter run -d windows
```

بار اول، از **تنظیمات ← ارائه‌دهنده‌های من** یک ارائه‌دهنده اضافه کنید و
کلیدتان را وارد کنید.

## کلید شما کجا می‌رود

کلید API فقط برای احراز هویت درخواست به endpoint ارائه‌دهندهٔ انتخابی شما
فرستاده می‌شود؛ هیچ سرویس متعلق به برنامه آن را دریافت نمی‌کند. کلید در حالت
ذخیره‌شده روی ویندوز با DPAPI محافظت می‌شود و در فایل پیکربندی یا «خروجی
گرفتن از تنظیمات» قرار نمی‌گیرد؛ برای این مرزها تست وجود دارد.

> ⚠ امروز فقط ویندوز پشتیبانی می‌شود. رمزگذاری کلید به DPAPI گره خورده و
> ابزار اجرای فرمان هم به `cmd`/`powershell` — روی لینوکس و مک هیچ‌کدام
> معادل ندارند. تا وقتی جایگزینشان نوشته نشده، این نسخه آنجا اجرا نمی‌شود،
> و این صادقانه‌تر از ذخیرهٔ کلید به‌صورت متن ساده است.

## هشدار امنیتی — این را جدی بخوانید

این برنامه روی دستگاه شما **فرمان اجرا می‌کند** و **فایل می‌نویسد**. این
قابلیت اصلی‌اش است، نه یک عارضه.

- حالت پیش‌فرض (**دستی**) پیش از هر عملیات مؤثر اجازه می‌گیرد. همان‌جا
  بمانید مگر دلیل روشنی داشته باشید.
- حالت **بی‌نظارت** عملیات فایل را بدون پرسش انجام می‌دهد، اما اجرای فرمان
  همیشه تأیید جداگانه می‌خواهد. فرمان‌های shell به پوشهٔ کاری محدود نیستند.
- ایجنت محتوای بیرونی می‌خواند: صفحهٔ وب، فایل، خروجی فرمان. اگر آن محتوا
  چیزی شبیه دستور داشته باشد، **داده** حساب می‌شود نه دستور، و خودِ موتور
  به شما گزارش می‌دهد که چنین چیزی دیده. این مرز تست دارد
  ([`test/desktop/prompt_injection_test.dart`](test/desktop/prompt_injection_test.dart)).

flutter analyze          # باید صفر خطا باشد

می‌دهند و نباید شامل جزئیات زیرساخت خصوصی باشند.
