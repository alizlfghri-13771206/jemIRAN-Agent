# معماری دسکتاپ

این پوشه رابط ویندوز، موتور ایجنت، ابزارهای محلی و تنظیمات ارائه‌دهنده‌های
BYOK را نگه می‌دارد. برنامه در حال حاضر فقط ویندوز را پشتیبانی می‌کند.

## مسیر اجرا

`main.dart` پوستهٔ دسکتاپ را باز می‌کند. فهرست مدل‌ها از تنظیمات محلی کاربر
ساخته می‌شود و درخواست مدل به endpoint انتخاب‌شده فرستاده می‌شود؛ پراکسی
اختیاری فقط وقتی در مسیر قرار می‌گیرد که خود کاربر آن را تنظیم کرده باشد.

## مرزهای دسترسی

- ابزارهای فایل فقط مسیرهای داخل منابعی را می‌پذیرند که کاربر انتخاب کرده است.
- نوشتن، حذف و عملیات مؤثر بر اساس حالت ایجنت تأیید می‌گیرند.
- فرمان shell با دسترسی حساب ویندوز اجرا می‌شود و sandbox فایل ندارد؛ به همین
  دلیل حتی در حالت بی‌نظارت نیز تأیید جداگانه می‌خواهد.
- محتوای وب و خروجی ابزارها دادهٔ غیرقابل‌اعتماد محسوب می‌شوند.

## پوشه‌ها

- `agent/`: حلقهٔ اجرا، سیاست دسترسی، ابزارها و adapterهای مدل
- `chat/`: رابط گفتگو و نمایش فعالیت
- `models/`: فهرست محلی مدل‌های قابل استفاده
- `routing/`: اولویت و failover ارائه‌دهنده‌ها
- `shell/`: پنجره، نوار کناری و tray
